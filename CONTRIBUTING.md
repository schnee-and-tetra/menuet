# Contributing to Menuet

Menuet is primarily a personal-use project, but contributions, bug reports, and discussions are welcome!

Please review the guidelines below before submitting a Pull Request.

## 🛠️ Development Guidelines

* **Project Base**: Forked from [MenuLibre](https://github.com/bluesabre/menulibre).
* **Tech Stack**: Built with Python, GTK 3, GTKSourceView 3, and PyGObject.
* **Target Environment**: Linux Mint Cinnamon only.
* **Desktop Integration**: Changes should preserve compatibility with the Cinnamon Menu and its menu/launcher behavior.

## ⚠️ Notes & Requests

* **Changes**: Major changes and feature additions are welcome, as long as they work correctly and do not introduce known regressions.
* **Target Scope**: Please keep changes focused on Linux Mint Cinnamon. Generic desktop-environment compatibility is outside the project's scope.
* **Response Time**: Please note that responses from the maintainer may take up to a month due to availability.
* **Code Quality**: Ensure your changes are tested and do not introduce known regressions before submitting a PR.

## 📝 Commit Messages

Please keep commit messages concise and descriptive.
